# ADR-0011 Agent 运行能力与资源策略

## 状态

已采用。

## 背景

ADR-0010 将步骤、时间、Token、成本、工具调用和并发统一定义为 Agent 执行边界中的硬上限。除并发外，这些硬上限会截断模型的推理、检索和验证深度；Token 又主要是成本的计量基础，不应形成另一套成本门槛。

## 决策

Agent 执行边界继续冻结能力集合、网络策略和每项能力的类型化约束，并对未知、越权、非法或缺失必需约束的请求 fail-closed。子任务并发上限是唯一保留的硬资源额度，只限制同时运行数量，通过 acquire/release 重复使用，不限制累计子任务数。

Agent Runner 创建一次运行时只取得一个不透明的 per-run `AgentExecution` handle。该 handle 隐藏执行边界冻结、工具 enforcement、子任务并发许可、用量观测和审计快照；Harness 只能接收由 handle 包装后的能力 adapter，不能取得或调用未包装的原始 adapter，调用方也不能绕过 handle 自行执行策略检查。

能力 adapter 只声明能力 ID、输入 Schema、类型化约束定义和实际执行，并保留传输层技术保护；它不得自行维护授权、网络或资源策略。`AgentExecution` module 统一拥有交互模式能力上限、显式能力收窄、网络策略、能力约束校验、子任务并发许可和运行审计。

外部调用方不得提交任意形状的已冻结执行边界，只能提交类型化的策略收窄请求，包括能力集合及其约束、网络收窄、子任务并发上限和可选成本软阈值。`AgentExecution` module 根据交互模式授权上限在内部冻结执行边界；暂停恢复只能读取系统已经保存的冻结快照，不能重新接受调用方策略输入。

系统不设置 Agent 总运行时间、步骤、Token 或工具调用次数上限；这些用量只进入运行审计，不参与执行准入或停止判断。成本软阈值可以按任务配置，但只产生审计超限记录，不阻塞或停止模型调用；未配置或成本未知时也不阻塞。成本软阈值使用显式 `USD` 币种和整数微美元表示，module 将 adapter 返回的美元成本转换为微美元后累计比较，避免无币种数字和浮点临界误差。成本采用模型 adapter 返回的实际用量与成本，不另设独立计价来源，未知成本不得记作零或参与阈值比较。

模型与工具 adapter 可以保留超时、响应大小、限流、有限重试和 Provider 上下文窗口等技术保护，但不得把它们提升为另一套业务预算。等待用户输入只是同一次逻辑运行的暂停：恢复时沿用冻结的能力策略，暂停前后的用量合并审计，并发额度则在暂停时释放、恢复时重新取得。

本 ADR 仅取代 ADR-0010 中 Agent 运行的资源限制、预算耗尽和相关审计语义；ADR-0010 的其他自主边界与人在回路决定继续有效。
