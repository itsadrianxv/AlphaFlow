# 显式研究关注与冻结偏好快照

AlphaFlow 私测版只使用用户明确设置的研究关注进行个性化，不采集或派生行为兴趣。研究偏好模块在 PostgreSQL 保存可变的当前启用状态、用户级分发开关和常规/重点研究关注，并通过一个窄接口冻结规范化、带契约版本且不可变的研究偏好快照，供相关性评估与分发门控共同消费；调用方不直接拼装偏好输入。首页生成不依赖这份快照，仍按 ADR-0008 直接消费个性化清单创建时冻结的偏好内容。

当前偏好修改通过统一的幂等写入事务生效并只影响后续冻结，已经排队的内容继续使用入队时的最终分发结果。快照固定契约版本、启用状态、分发开关、规范化关注对象与级别、冻结时间和内容哈希；相同内容可幂等复用。MVP 不建立偏好版本、偏好指纹或其他替代身份键，首页个性化清单继续直接冻结创建时的偏好内容。清除研究偏好时删除当前关注与可删除的偏好快照，历史收件箱内容保留但不再承诺重放已删除的个性化输入，个人信息删除优先于完整历史重放。

MVP 不创建行为日志副本、兴趣线索、衰减权重、兴趣传播或行为设置表。“稍后”以及“有用 / 噪声”继续属于阅读管理和质量反馈模块，不跨越研究偏好模块的 seam。行为兴趣只有在私测真实数据证明其价值、风险与可解释性后，才作为新的规划工作重新决策。
