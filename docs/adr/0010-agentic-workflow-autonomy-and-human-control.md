# ADR-0010 Agentic Workflow 自主边界与人在回路

## 状态

已采用。

其中 Agent 运行的资源限制语义已由 [ADR-0011](./0011-agent-runtime-capability-and-resource-policy.md) 取代；其余决定继续有效。

## 背景

AlphaFlow 同时存在后台研究事件生产、分发评估、简报与持续追踪，以及由 Pi Agent Harness 驱动的前台即时研究。系统需要允许 Agent 自主检索、分析和组织表达，又不能让模型输出直接成为权威状态或绕过 `research_only` 与分发纪律。

## 决策

### Agent Runner 与本地确定性结算

`Agent Runner` 接收一次冻结的 Agent 执行边界，边界包含目标、输入快照与幂等身份、能力集合、网络策略，以及步骤、时间、Token、成本、工具调用和并发上限；它返回结构化结果、证据缺口、停止原因和审计摘要。Agent 可以在边界内选择 Skill、工具、调用顺序和共享预算的并发子任务，但不能扩展目标、权限或预算，也不能安装或修改 Skill、取得新凭据或执行未登记命令。

系统不设置统一的 `Deterministic Controller` module 或远程结算路径。每个业务调用方在 Agent Runner 返回后，通过贴近业务的本地确定性 guard/module 校验输出 Schema、引用闭合、版本、权限和执行边界，再幂等结算其拥有的领域状态、用户意图、分发门控或外部投递。共同规则可以复用独立 module，但不能形成掌握全部工作流的中央编排器。研究事件裁定、分发评估和简报表达中的语义判断仍由 Agent 或 LLM 完成；代码不重复扮演业务裁判，合法结果可以自动结算，无需用户或运营人员逐项批准。

### 开放网页与证据补全

Agent 可以通过受控抓取能力发现并访问任意公开 HTTP(S) 网页，采集阶段不以来源可信度白名单预先拦截；不得访问内网或本机地址、使用应用凭据、绕过登录、付费墙或其他访问控制。网页材料先作为来源身份和证据资格尚未裁定的候选材料，不能直接成为权威数据观测、研究事件或主动分发内容。

研究事件裁定前可以运行有界的证据补全任务，多轮检索来源、反证和来源身份线索；任务结束后冻结证据集合，再执行一次候选裁定。裁定期间不动态扩充证据，后续实质证据通过新的候选修订触发重裁定。

MVP 不实现网页提示注入识别或标记，也不在运行时判定材料的数据权利或系统整体合规资格。供应商授权和上线合规仍是系统外部的发布前置事项；`research_only` 输出约束继续由确定性代码执行。

### 后台工作流与即时研究

专业市场基线、个性化研究雷达、研究收件箱、定时简报和紧急提醒只能消费已经结算的数据观测修订、研究事件修订、证据、分发评估和冻结研究偏好。临时网页材料必须先经过候选裁定和确定性写入，不能直接进入后台产物。

即时研究是唯一允许直接使用当次网页证据形成用户回答的路径。它不为复用而主动查询、匹配或等待权威对象；正常检索恰好命中已有数据观测、研究事件或证据修订时才采用，否则继续当次研究。新发现只能在响应后作为候选种子异步、幂等回灌，不能同步修改全局研究事件、研究收件箱或分发状态。

研究智能体按 Pi Agent Harness 会话连续运行，由 Harness 负责持久化、恢复和压缩上下文；关键歧义可以暂停并逐问用户，次要缺口则声明假设后继续。事件裁定、分发评估、简报、持续追踪和定时任务均以冻结输入运行，不等待用户输入，缺少必要输入时返回结构化缺口并结束或暂缓。

### 简报、追踪与分发

确定性代码按分发评估、研究关注、修订状态、渠道门槛和容量冻结简报选材；Agent 只在冻结集合内组织叙事、变化、风险与后续验证项，不得新增事实、删除必显更正或撤回、改变渠道或发送内容。

全局事件核实的持续追踪计划可以自动激活，但必须包含待验证事实、合格证据、触发条件、检查频率、到期时间和资源上限。个性化持续追踪只能来自已有研究关注或用户当次确认；命中只产生新证据或候选修订，不直接形成研究事件或用户分发。

用户开启外部提醒渠道并完成授权后形成持续预授权。通过确定性门控的紧急提醒、定时简报、更正和撤回通知可以自动发送；Agent 不选择收件人、渠道或发送时机，也不直接调用外部发送工具。新增渠道、扩大接收范围、重新授权凭据或恢复已关闭渠道必须再次由用户确认。

### 人在回路与 `research_only`

MVP 的人在回路只负责用户自身副作用授权，不建设运营人工复核或异常处置队列。用户明确、单义且可撤销的自然语言指令本身可以作为确认；对象含糊、批量变更、扩大外部分发、访问受限资源或不可恢复操作必须展示精确影响并二次确认。Agent 只提出结构化意图，确定性代码负责对象解析、权限与确认等级校验和最终写入。

用户要求买卖、持有、加减仓、仓位、入场价、目标价、止损价或订单计划时，确定性 `research_only` 约束拒绝执行性部分；研究智能体不为此追问持仓或风险偏好，但仍可提供相关事实、证据、不确定性、正反情景、风险因素、判断条件和后续验证项。Skill、网页、附件或其他输出形态不能绕过该约束。

### 失败与审计

证据不足或冲突按既有规则形成暂缓候选；Agent 输出契约非法或越过执行边界时不结算，并在上限内重试。预算耗尽后返回部分结果、缺口和停止原因。有既往有效修订时，更新技术失败继续保留上一有效修订；已确认的更正或撤回由代码创建新修订并按既有规则通知，不等待人工批准。

每次运行至少记录任务身份和发起者、父子任务关系、输入快照或哈希、执行边界、Skill/工具/模型版本、工具调用摘要和来源、最终结构化输出、校验结果、停止原因、Token/成本/耗时及后续领域对象或意图记录。审计不保存隐藏推理过程，也不要求永久保存所有网页全文；研究智能体会话继续由 Harness 保存。

## 后果

该设计把自主性集中在检索、语义判断和表达，把权威写入与外部副作用留在各业务调用方不可绕过的本地确定性 guards，以缩短热路径并保持业务 locality；后台产物没有临时网页旁路，即时研究又不必等待完整事件生产。MVP 明确延期运营审核工作台、运行时数据权利/整体合规资格判断和网页提示注入治理，实施规格不得把这些延期项暗中重新引入。
