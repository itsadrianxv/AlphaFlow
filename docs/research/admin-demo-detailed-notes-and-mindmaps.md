# admin 演示收藏对象详细笔记与思维导图调研

> 调研日期：2026-08-04  
> 适用范围：本机演示数据。以下内容用于展示研究框架、证据追踪和跨对象影响映射，不构成投资建议。笔记刻意不写会快速失效的即时价格、估值和单期预测值；演示时应从引用入口刷新数据。

## 落库建议

- 每个收藏对象建立一条独立研究笔记，并关联一张同名思维导图；自选股列表再建立一条组合层笔记和导图。
- 笔记正文保留“研究定位、核心驱动、关键指标、事件触发器、风险与反证、跨对象关联、证据入口”七部分。
- 思维导图至少包含 6 个一级分支，每个一级分支至少 2 个二级节点；节点只表达待验证关系，不写买卖结论。
- 年报、公告与监管数据库是事实层；研究假设和指标变化属于解释层。演示时应明确区分两层。

## 收藏公司

### 1. 宁德时代（300750）

**建议笔记标题：** 宁德时代：动力电池与储能的需求、技术和资源闭环

**研究定位：** 以动力电池和储能电池为核心，观察新能源汽车渗透、储能建设、电池技术迭代、原材料价格与全球产能布局如何共同影响经营质量。

- **核心驱动：** 下游新能源车销量及单车带电量；储能装机与系统需求；产品结构和技术路线；海外客户及本地化供应；上游锂、镍、钴等材料成本；产能利用率与现金回收。
- **关键指标：** 动力/储能电池销量或出货口径、分业务收入与毛利率、研发投入、产能与利用率、库存和应收周转、经营现金流、资本开支、主要原材料价格。
- **事件触发器：** 定期报告、重要客户定点或合作、新产品/新技术发布、海外工厂进展、储能政策和项目、原材料供需变化、产品质量或召回事项。
- **风险与反证：** 新能源车或储能需求弱于预期；价格竞争抵消出货增长；技术路线迁移削弱既有优势；海外监管和贸易壁垒；原材料成本与售价错配；扩产后利用率下降。反证应优先检查订单、利用率、单位盈利与现金流是否同步走弱。
- **跨对象关联：** 上游连接紫金矿业及有色金属；下游连接比亚迪和汽车行业；储能连接阳光电源、电力设备与能源政策；制造设备和芯片需求连接电子行业。

### 2. 比亚迪（002594）

**建议笔记标题：** 比亚迪：垂直一体化整车平台与全球化经营观察

**研究定位：** 以新能源汽车整车为主线，同时观察电池、功率半导体和汽车电子的一体化能力，重点拆分销量、车型结构、出口、本地化生产和渠道效率。

- **核心驱动：** 新车型周期、插混与纯电结构、国内外销量、品牌上探、出口和海外建厂、供应链自制率、规模效应与渠道覆盖。
- **关键指标：** 分车型/动力类型产销、海外销量、单车收入、汽车业务毛利率、研发投入、存货和应收、经营现金流、资本开支、经销网络及产能利用。
- **事件触发器：** 月度产销快报、车型上市和改款、价格或权益调整、海外市场准入与工厂进展、智能驾驶和电动化技术发布、召回与质量公告。
- **风险与反证：** 行业价格竞争、产品节奏失误、出口贸易壁垒、海外渠道和本地化成本、库存上升、质量安全事件。销量增长但库存、促销和现金占用同步上升，是需重点验证的反证组合。
- **跨对象关联：** 电池链连接宁德时代与电力设备；车规芯片连接中芯国际和电子；铜等材料连接紫金矿业和有色金属；出口数据连接海关总署。

```text
│ └─海外：出口 / 本地销售 / 区域结构
├─产品周期
│ ├─品牌矩阵：大众 / 高端 / 专业化

│ ├─量价利：销量 / 单车收入 / 毛利
│ └─周转：库存 / 应收 / 现金流 / 资本开支
├─外部环境
│ ├─政策：购置税 / 以旧换新 / 双积分
│ └─全球化：关税 / 准入 / 本地化生产
└─触发器与反证
  ├─触发器：产销快报 / 新车 / 技术发布 / 海外工厂
  └─反证：降价换量 / 库存累积 / 质量事件 / 贸易壁垒
```

### 3. 中芯国际（688981）

**建议笔记标题：** 中芯国际：晶圆代工周期、工艺平台与国产供应链验证

**研究定位：** 以晶圆代工的需求周期和产能利用为核心，观察工艺平台、产品组合、客户库存、扩产强度及设备材料供应约束。

- **核心驱动：** 消费电子和工业/汽车芯片需求、客户库存周期、晶圆价格、产能利用率、成熟及特色工艺平台扩张、国产设备材料验证、资本开支和折旧节奏。
- **关键指标：** 晶圆收入、产能利用率、平均售价、分应用收入结构、毛利率、折旧、资本开支、在建工程、研发投入、存货和客户预付款。
- **事件触发器：** 季度业绩与经营展望、新产线投产、工艺平台进展、客户库存拐点、半导体设备政策、出口管制变化、重大供应链事项。
- **风险与反证：** 行业下行期扩产导致利用率和毛利承压；关键设备材料受限；客户需求恢复不及预期；技术投入转化慢。收入增长若主要来自新增产能而利用率、售价和现金流走弱，应视为重要反证。
- **跨对象关联：** 下游连接工业富联、计算机和汽车；上游连接电子行业内设备、材料；AI 需求通过服务器、网络设备间接传导，不应把先进算力需求等同于全部晶圆产能受益。

```text
│ ├─产能：投产 / 爬坡 / 利用率

│ └─政策环境：许可 / 出口管制 / 产业支持
├─财务验证
│ ├─收入桥：晶圆量 / 平均售价 / 产品组合

  ├─触发器：季报 / 指引 / 新线 / 库存拐点
```

### 4. 工业富联（601138）

**建议笔记标题：** 工业富联：AI 服务器、网络设备与精密制造的需求传导

**研究定位：** 区分 AI 算力基础设施带来的服务器和高速网络需求，与传统云、通信及消费电子精密制造周期，验证订单增长能否转化为利润和现金流。

- **核心驱动：** 云服务商资本开支、AI 服务器与高速网络升级、产品结构、关键客户需求、供应链交付、自动化和规模制造效率。
- **关键指标：** 分业务收入和毛利、AI 相关产品口径及占比、研发投入、客户集中度、存货和应收、合同负债、经营现金流、资本开支。
- **事件触发器：** 定期报告、算力产品发布、重要客户资本开支变化、产能扩建、数字基础设施政策、供应链交付或组件短缺。
- **风险与反证：** 客户集中、AI 需求与确认收入时间错配、低毛利代工属性、关键组件供应受限、资本开支周期反转。主题热度上升但毛利、现金流和订单披露没有改善，是关键反证。
- **跨对象关联：** 上游连接中芯国际及电子元器件；下游连接计算机行业、云和运营商；制造环节受铜、能源与汇率影响。

### 5. 恒瑞医药（600276）

**建议笔记标题：** 恒瑞医药：研发管线、注册里程碑与商业化兑现

**研究定位：** 按靶点、适应症和临床阶段拆解创新药管线，追踪临床、注册、医保、商业化和对外授权的证据链，避免仅按研发项目数量判断价值。

- **核心驱动：** 关键临床读出、获批适应症、医保准入、院内覆盖、创新药收入占比、海外授权和里程碑、研发效率。
- **关键指标：** 各阶段管线数量及关键项目进度、研发费用、资本化政策、获批和纳入医保情况、分产品收入、销售费用、应收和经营现金流、授权首付款及里程碑。
- **事件触发器：** 临床试验登记和结果、NDA/BLA 受理或批准、适应症扩展、医保目录调整、对外许可、专利争议和药物警戒信息。
- **风险与反证：** 临床失败或延迟、同靶点竞争拥挤、集采和医保降价、商业化不及预期、安全性信号、授权回款不确定。项目推进但患者入组、关键终点或销售放量未验证，应降低结论强度。
- **跨对象关联：** 医药生物行业受药监、医保、医院采购共同影响；消费和银行宏观变量并非直接驱动，需避免过度传播。

```text
├─临床证据
│ ├─设计：对照 / 终点 / 样本 / 入组
```

### 6. 贵州茅台（600519）

**建议笔记标题：** 贵州茅台：品牌供给、渠道秩序与现金流质量

**研究定位：** 从有限供给、产品结构、直销与经销渠道、终端动销和社会库存解释经营表现，区分出厂价格、公司确认收入与终端价格。

- **核心驱动：** 基酒产能与可售量、产品结构、出厂政策、直销占比、经销商网络、节庆和商务需求、渠道库存、品牌投入和股东回报。
- **关键指标：** 茅台酒/系列酒收入和销量、吨价、直销与批发渠道收入、合同负债、经销商增减、存货结构、经营现金流、税费、分红。
- **事件触发器：** 定期报告、出厂价或渠道政策、产品投放、经销商调整、股东回报安排、食品安全事件、社会消费品零售数据。
- **风险与反证：** 终端需求减弱、渠道库存累积、批价与出厂价偏离扩大、系列酒培育不及预期、监管和消费环境变化。合同负债、现金回款和动销若与收入趋势背离，需要重新验证渠道质量。
- **跨对象关联：** 对应食品饮料与消费景气；银行财富效应和企业活动可能形成间接关联，但不应将短期宏观数据机械映射为公司销量。

```text
贵州茅台研究框架
├─供给约束
```

- **触发器：** 社零和餐饮数据、价格与渠道政策、经销商变化、原料价格、食品安全抽检、股东回报。
- **风险/反证：** 需求疲弱、渠道压货、价格倒挂、食品安全、成本上涨；收入增长若伴随库存、应收和促销费用上升，需验证真实动销。
- **对象关联：** 贵州茅台作为高端白酒与渠道样本，招商银行通过居民财富和企业活动形成间接宏观参照。

```text
食品饮料行业
├─需求：居民收入 / 餐饮 / 节庆 / 商务活动
├─品类：白酒 / 乳品 / 调味品 / 饮料食品
├─渠道：经销 / 直营 / 电商 / 库存与动销
├─量价成本：销量 / 售价 / 原料包装 / 毛利
├─风险：食品安全 / 渠道压货 / 价格倒挂

```

### 15. 银行（申万2021一级行业）

**建议笔记标题：** 银行：利率、信用、非息收入和资本约束

**研究定位：** 用资产负债定价解释净息差，用逾期和迁徙前瞻资产质量，再结合手续费、拨备、资本与分红评估利润质量。

- **驱动与指标：** 政策利率和 LPR、存贷款结构与定价、信贷需求、不良生成、拨备、手续费收入、资本充足率和流动性。
- **触发器：** 央行货币政策、LPR 和存款利率、金融监管数据、房地产和地方债政策、资本规则、定期报告及分红。
- **风险/反证：** 息差下降、信用成本上升、非息收入波动、资本不足；账面不良稳定但关注、逾期和迁徙率恶化是前瞻反证。
- **对象关联：** 招商银行作为零售与财富管理样本；各制造、消费、资源对象构成不同对公和零售信用周期映射。

```text
银行行业

├─息差：资产收益率 / 负债成本 / 重定价 / 结构
├─信用：关注 / 逾期 / 不良生成 / 拨备核销
├─非息：财富管理 / 结算 / 投资收益 / 手续费
├─资本：资本充足 / 风险权重 / 分红 / 流动性
```

### 17. 跨行业研究观察池（10只）

**建议笔记标题：** 跨行业研究观察池：事件传播、因子暴露与组合反证

**研究定位：** 该列表不是模拟持仓，而是一组跨产业链观测器。研究重点是事件先影响哪个对象、如何沿上下游或宏观变量传播，以及不同对象能否提供交叉验证。

- **十只对象的角色：** 宁德时代（动力/储能电池）、比亚迪（整车）、阳光电源（光伏逆变器/储能系统）、中芯国际（晶圆代工）、工业富联（AI服务器/网络制造）、恒瑞医药（创新药）、贵州茅台（消费与渠道）、招商银行（利率与信用）、紫金矿业（铜金资源）、中国海油（油气供给与资本开支）。
- **共同指标面板：** 收入增长来源、毛利与费用、经营现金流、库存/应收、资本开支、股东回报；再为每家公司保留 2 至 4 个行业专属指标。
- **事件传播：** 铜价影响紫金矿业的产品价格，也可能影响电网、汽车和服务器成本；利率通过招商银行息差、黄金定价、成长型资本开支产生不同方向影响；AI资本开支从工业富联向芯片、网络和电力需求传播。

## 数据刷新与演示口径

1. **公司事实**：优先从交易所公告或公司定期报告刷新；官网新闻只能作为事件线索，不能替代法定披露。
2. **行业事实**：优先使用主管部门、国家统计局、海关、交易所和电网招标数据；不同来源的统计范围和时间频率必须保留。
3. **思维导图节点**：一级节点保持稳定，二级节点可随新证据增删；每个结论节点应记录来源 URL、发布日期和最后核验时间。
4. **避免伪精确**：演示数据不预填目标价、收益率预测或即时估值；任何方向性假设都必须同时写失效条件。
5. **避免重复计算**：同一宏观事件可能同时命中公司、行业和自选股，聚合时按事件 ID 去重，并显示传播路径而非重复计数。
